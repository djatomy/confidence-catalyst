# Confidence Catalyst (コンフィデンス・カタリスト)

大切な面談や対話の前に、ユーザーの緊張を解きほぐし、本来持っている自信（輝き）を呼び起こすための「静かな儀式」を提供する対面戦略シミュレーターです。

---

## 1. コンセプト
**「本来の輝きへ回帰する」**
科学的なアプローチとマインドフルネスな体験を融合。ユーザーの属性や現在の状態を分析し、お相手のタイプに合わせた最適なアドバイスを提示することで、確信を持って対話に臨めるようサポートします。

## 2. 主な機能
* **パーソナライズ入力**: ユーザー名、生年月日、お相手の情報（任意）、および「光・地・月・森」の4つの属性から自分に合うものを選択。
* **同調（Sync）プロセス**: 画面上のオーブを長押しすることで、触覚フィードバック（バイブレーション）と共に心を整える待機時間を演出。
* **インサイト分析**:
    * 「こころのパワー」と「相手への伝わりやすさ」をスコア化。
    * 属性に基づいたシンボルとアートワークの表示。
    * お相手との相性診断および具体的なコミュニケーションアドバイス。
* **リリースメッセージ**: 対話直前に心を落ち着かせるための、3段階のステップメッセージを表示。

## 3. 技術スタック
* **Frontend**: HTML5, CSS3, JavaScript (Vanilla JS)
* **UI/UX**:
    * グラスモーフィズム（透過要素）デザイン
    * CSS Transitions による滑らかな画面遷移
    * Web Vibration API によるハプティクス（触覚）フィードバック
* **Data Management**: `localStorage` を使用した入力内容の永続化

## 4. ファイル構成
* `index.html`: アプリケーションの構造定義。
* `app.js`: 画面遷移、状態管理、アニメーション、および `localStorage` 連携のロジック。
* `data.js`: 診断メッセージ、アドバイス、シンボル定義などのマスターデータ。
* `styles.css`: 視覚的なスタイリング（※外部参照）。
* **Assets**:
    * `light_art.jpg`: 「光」属性のアートワーク
    * `earth_art.jpg`: 「地」属性のアートワーク
    * `moon_art.jpg`: 「月」属性のアートワーク
    * `sea_art.jpg`: 「森」属性のアートワーク（※内部ロジック上、森として処理）

## 5. 属性とシンボルの定義

| 属性 | キーワード | シンボル例 |
| :--- | :--- | :--- |
| **光 (Light)** | 直感・ひらめき | ぽかぽかの日 |
| **地 (Earth)** | 安定・揺るぎなさ | どっしりした山 |
| **月 (Moon)** | 共感・寄り添い | 静かな月明かり |
| **森 (Forest)** | 包容力・本質 | 深い緑の森 |
