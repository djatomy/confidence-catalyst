提供されたソースコードおよびアセットファイルに基づき、このアプリケーションの README.md を作成しました。Confidence Catalyst (コンフィデンス・カタリスト)Confidence Catalyst は、大切な面談や対話の前に、ユーザーの緊張を解きほぐし、本来持っている自信（輝き）を呼び起こすための「静かな儀式」を提供する対面戦略シミュレーターです。1. コンセプト「本来の輝きへ回帰する」をテーマに、科学的なアプローチとマインドフルネスな体験を融合。ユーザーの属性や現在の状態を分析し、お相手のタイプに合わせた最適なアドバイスを提示することで、確信を持って対話に臨めるようサポートします。2. 主な機能パーソナライズ入力: ユーザー名、生年月日、お相手の情報（任意）、および「光・地・月・森」の4つの属性から自分に合うものを選択します。同調（Sync）プロセス: 画面上のオーブを長押しすることで、触覚フィードバック（バイブレーション）と共に心を整える待機時間を演出します。インサイト分析:「こころのパワー」と「相手への伝わりやすさ」のスコア化。属性に基づいたシンボルとアートワークの表示。お相手との相性診断および具体的なコミュニケーションアドバイス。リリースメッセージ: 対話直前に心を落ち着かせるための、3段階のステップメッセージを表示します。3. 技術スタックFrontend: HTML5, CSS3, JavaScript (Vanilla JS)UI/UX:グラスモーフィズムデザインCSS Transitions による滑らかな画面遷移Web Vibration API によるハプティクスフィードバックData Management: localStorage を使用した入力内容の永続化4. ファイル構成index.html: アプリケーションの構造定義。app.js: 画面遷移、状態管理、アニメーション、および localStorage 連携のロジック。data.js: 診断メッセージ、アドバイス、シンボル定義などのマスターデータ。styles.css: 視覚的なスタイリング（※ファイル内容は未提供ですが、HTMLから参照されています）。Assets:light_art.jpg: 「光」属性のアートワークearth_art.jpg: 「地」属性のアートワークmoon_art.jpg: 「月」属性のアートワークsea_art.jpg: 「森」属性のアートワーク（※内部的に森として処理されます）5. 属性とシンボルの定義属性キーワードシンボル例光 (Light)直感・ひらめきぽかぽかの日地 (Earth)安定・揺るぎなさどっしりした山月 (Moon)共感・寄り添い静かな月明かり森 (Forest)包容力・本質深い緑の森
